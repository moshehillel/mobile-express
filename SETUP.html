Full Setup Guide

Everything you need to install and run this system on a new computer with new accounts from scratch.

System Overview

This program has four parts that work together:

  • Website — A store where customers browse phones, place web orders, and check order status. Hosted on Netlify.
  • IVR Phone System — A fully automated phone ordering system. Customers call a number and order using their keypad. Hosted on Twilio.
  • Airtable Database — All orders (web and phone) are saved here. You manage and fulfill orders from the Airtable spreadsheet or from the admin page.
  • Local Admin Server — Runs on your own computer. Lets you manage website products, edit IVR messages, and deploy changes — all without touching code.

Step 1 — Computer Setup

Before anything else, install the following on your computer:

Install Node.js

Download and install Node.js version 18 or newer from nodejs.org. This runs the local admin server.

Install Twilio CLI

Open a terminal (Command Prompt or PowerShell on Windows) and run:

npm install -g twilio-cli

After installing, log in to your Twilio account:

twilio login

Enter your Account SID and Auth Token when asked (you'll find these in Step 5 — Twilio).

Install project dependencies

Copy the project folder to your computer. Then open a terminal in that folder and run:

npm install

This installs everything the local server needs to run.

Step 2 — Airtable

Airtable is the database where all orders are saved. Both the website and the IVR phone system write orders here.

Create the base

  1. Go to airtable.com and sign up for a free account.
  2. Click Add a base → Start from scratch.
  3. Name the base anything you like (e.g. "Store Orders").

Set up the Orders table

Rename the default table to Orders. Then add the following columns in this exact order (the default "Name" column can be renamed to "Order Number"):

Column NameAirtable TypeNotes
Order NumberSingle line textAuto-generated 6-digit number
SourceSingle line textWill say "Web" or "IVR"
TimestampSingle line textDate and time of order
NameSingle line textCustomer name (web orders only)
PhoneSingle line textCustomer phone number
EmailEmailCustomer email (web orders only)
AddressLong textDelivery address
DetailsLong textWhat was ordered
SubtotalCurrency (USD)Order subtotal before tax
TaxCurrency (USD)NY sales tax 8.125%
TotalCurrency (USD)Final amount charged
PaymentSingle line textStripe payment confirmation code
Address RecordingURLLink to recorded address audio (IVR only)
StatusSingle line textProcessing / Shipped / Delivered
IMEISingle line textPhone IMEI — filled in when fulfilling
Tracking NumberSingle line textShipping tracking — filled in when fulfilling
Empty columns are fine. IVR orders won't have Name or Email. Web orders won't have Address Recording. IMEI and Tracking Number start blank and get filled in when you ship the order.

Get your Base ID and Table ID

Open the base in your browser. Look at the URL — it looks like this:

https://airtable.com/appXXXXXXXXXXXX/tblXXXXXXXXXXXX/viw...
  • The part starting with app... is your Base ID
  • The part starting with tbl... is your Table ID
  • Write both down — you'll need them later

Create a Personal Access Token

  1. Go to airtable.com/create/tokens
  2. Click Create new token
  3. Name it anything (e.g. "Store App")
  4. Scopes: add data.records:read and data.records:write
  5. Access: choose Add a base → select your base only
  6. Click Create token
  7. Copy the token immediately — you will not be able to see it again
Important: Never paste this token into any code file or share it in a message. It goes only in environment variables (covered below). If it is ever exposed, delete it at airtable.com/create/tokens and generate a new one.

Step 3 — Gmail

The system uses Gmail to send order confirmation emails to customers and notification emails to the store owner.

Enable App Password

  1. Go to myaccount.google.com → Security
  2. Make sure 2-Step Verification is turned on (required)
  3. Search for App Passwords in the search bar
  4. Click App Passwords → Select app: Mail → Select device: Other → type "Store"
  5. Click Generate
  6. Copy the 16-character password shown — you will not see it again
The App Password is different from your regular Gmail password. It is a special password that lets the app send emails on your behalf without needing your full Google account access.

Step 4 — Netlify (Website)

Netlify hosts the website and runs the backend functions that handle web orders, order status lookups, and the order fulfillment admin page.

Deploy the site

  1. Go to netlify.com and create a free account
  2. Click Add new site → Deploy manually
  3. Drag and drop your project folder onto the Netlify deploy area
  4. Wait for deployment to complete — you'll get a URL like https://random-name.netlify.app

Add a custom domain (optional)

  1. In Netlify: Site settings → Domain management → Add custom domain
  2. Follow the instructions to point your domain's DNS to Netlify

Add environment variables to Netlify

Go to Site settings → Environment variables → Add variable and add each of these:

Variable NameValueWhere to get it
AIRTABLE_TOKENYour Airtable Personal Access TokenCreated in Step 2
GMAIL_USERYour Gmail address (e.g. yourname@gmail.com)Your Gmail account
GMAIL_APP_PASSThe 16-character App PasswordGenerated in Step 3
ADMIN_PASSWORDA password for the process_orders.html pageYou choose this — keep it private
After adding environment variables, you must redeploy the site for them to take effect. Go to Deploys → Trigger deploy → Deploy site.

Note your site URL

Write down your Netlify URL (e.g. https://yoursite.netlify.app or your custom domain). You'll need it when setting up Twilio.

Step 5 — Twilio (IVR Phone System)

Twilio handles the entire phone system — the phone number customers call, the automated voice menus, credit card processing, and the recording of delivery addresses.

5a — Create your Twilio account

  1. Go to twilio.com → sign up for a free account
  2. Verify your email and phone number
  3. From the Console dashboard, write down:
    • Account SID (starts with AC...)
    • Auth Token (click to reveal)

5b — Get a phone number

  1. In the Twilio Console: Phone Numbers → Manage → Buy a number
  2. Search for a number in your area (make sure Voice capability is checked)
  3. Buy it — leave the configuration for now, you'll connect it to the flow in Step 5g

5c — Connect Stripe for payments

  1. Create a Stripe account at stripe.com if you don't have one
  2. In Twilio Console: go to Voice → Pay Connectors
  3. Click Create new Pay Connector → choose Stripe
  4. Name it exactly: Stripe_Connector_3 (this name is used in the flow — if you choose a different name, update it in the pay_1 widget of twilio.json)
  5. Connect your Stripe account by following the prompts

5d — Create the Functions Service

The IVR uses Twilio Functions (small programs that run on Twilio's servers). You need to create a service and add the functions to it.

  1. In Twilio Console: Functions & Assets → Services → Create Service
  2. Name it anything (e.g. my-ivr) — this becomes part of your function URLs
  3. Click Create

5e — Add the Functions

You need to create three functions inside the service. Click Add Function for each one and paste in the code from the local files listed below:

/phones_total
Function path in Twilio: /phones_total — Copy code from local file: twilio_phones_total

Calculates the order total. Reads the product catalog (phones, accessories, SIM) and returns the subtotal, tax, and total amount spoken aloud to the caller.

/place_order
Function path in Twilio: /place_order — Copy code from local file: twilio_place_order

Saves the completed order to Airtable and sends an email notification to the store owner after payment is confirmed.

/assistance
Function path in Twilio: /assistance — Copy code from the seller's existing Twilio account

Handles failed orders and customer callback requests. This function does not have a local file — you must copy the code directly from the seller's Twilio Functions service.

The /assistance function must be copied from the original Twilio account. Ask the seller to give you the code for that function. Without it, failed orders and callback requests will not work.

5f — Add dependencies to the service

The place_order function uses the nodemailer package to send emails. In the Functions editor:

  1. Click Dependencies (left panel)
  2. Add: nodemailer — use the latest version
  3. Save

5g — Add environment variables to the Functions service

Click Environment Variables in the left panel and add:

Variable NameValue
AIRTABLE_TOKENSame Airtable token as Netlify
GMAIL_USERSame Gmail address as Netlify
GMAIL_APP_PASSSame App Password as Netlify
ACCOUNT_SIDYour Twilio Account SID
AUTH_TOKENYour Twilio Auth Token

5h — Deploy the Functions service

  1. Click the Deploy All button in the Twilio Functions editor
  2. Wait for deployment to complete
  3. Write down the service domain shown at the top — it looks like my-ivr-XXXX.twil.io

5j — Create the Studio Flow

  1. In Twilio Console: Studio → Flows → Create new Flow
  2. Name it anything (e.g. "IVR Main Flow")
  3. Choose Import from JSON
  4. Open the local file twilio.json, copy its entire contents, and paste it in
  5. Click Next — the flow will load with all the widgets
  6. Click Publish
  7. Write down the Flow SID from the URL (starts with FW...)
Before importing twilio.json, make sure you have already completed the code changes in Step 6 below. The flow references your specific service domain and SIDs — if those are wrong, the functions will not work.

5k — Connect your phone number to the flow

  1. Go to Phone Numbers → Manage → Active numbers → click your number
  2. Under Voice & Fax → A call comes in
  3. Select Studio Flow from the dropdown
  4. Choose your newly created flow
  5. Save

Step 8 — Local Admin Server

The local server runs on your own computer and gives you access to three admin pages. It does not need to be online for the website or IVR to work — it is only used when you want to make changes.

Shortcut bat files

The project folder contains double-clickable bat files for every common task. You do not need to open a terminal:

FileWhat it does
START.batStarts the local server and opens the admin home page — choose Edit Website or Edit IVR from there
PUBLISH-TWILIO.batDeploys the phones_total function to Twilio, then publishes the Studio Flow — does everything in one click
PUBLISH.batDeploys the website and backend functions to Netlify

Admin pages

PageURLWhat it does
Website productshttp://localhost:5173/admin.htmlAdd, edit, delete products shown on the website storefront
IVR editorhttp://localhost:5173/admin-ivr.htmlEdit the phone menu messages and product catalog for the IVR system
Process ordershttp://localhost:5173/process_orders.html (or live site URL)Look up orders, add IMEI numbers and tracking numbers, update status

How to update IVR messages and pricing

  1. Double-click START.bat — the server starts and the admin home opens in your browser, then click Edit IVR
  2. Edit the phone menu text and/or the product catalog
  3. Changes save automatically a few seconds after you stop typing — no button needed
  4. When ready to go live, double-click PUBLISH-TWILIO.bat — it deploys the function and the Studio Flow in one step
PUBLISH-TWILIO.bat requires twilio-local.json to be set up (see Step 6) and the Twilio CLI to be logged in (twilio login). If twilio-local.json is missing, the function will not be deployed but the Studio Flow will still publish.

How to update website products

  1. Double-click START.bat — the server starts and the website admin opens in your browser
  2. Add or edit products
  3. Double-click PUBLISH.bat to deploy the updated site to Netlify

Step 9 — Test Checklist

After completing the setup, go through this checklist to make sure everything works:

  1. Airtable — Open the base and confirm the Orders table has all 16 columns.
  2. Website order — Go to your Netlify site, add a product to the cart, and complete a test checkout. Check that:
    • An order appears in Airtable
    • You receive a notification email
    • The customer receives a confirmation email
  3. Order status page — Go to the order-status page on your site, enter the phone number used in the test order, and confirm the order details appear.
  4. Process orders page — Open process_orders.html, log in, search for the test order, and try updating the status and adding a tracking number. Confirm the change appears in Airtable.
  5. IVR phone call — Call your Twilio phone number and go through the menus. Test:
    • Welcome menu plays correctly
    • Items menu reads the correct products
    • Total calculation works (subtotal + tax)
    • Payment screen appears (Stripe)
    • After payment, order appears in Airtable
    • Order status lookup works by caller ID
  6. IVR editor — Double-click START.bat, click Edit IVR, change the items menu text, and wait for "Saved and applied ✓" to appear. Then double-click PUBLISH-TWILIO.bat. Call the phone again and confirm the new message is heard.
Need help? If something isn't working, check the Netlify function logs (Netlify → Functions → your function → Logs) and the Twilio debugger (Twilio Console → Monitor → Errors) for error messages.
